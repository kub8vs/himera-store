# HIMERA — strona (Vercel)

Statyczna wersja strony Himery do podglądu i akceptacji przed przeniesieniem designu na motyw Shopify.

- `index.html` — strona główna z animowanym wejściem (parking nocą, wjazd auta, postać Himery)
- `sklep.html` — sklep: baner top 3 i katalog
- `style.css`, `site.js` — wspólne style i skrypty (koszyk, menu mobilne)
- `img/` — grafiki

## Vercel

Add New → Project → wybierz `kub8vs/himera-store` → **Root Directory: `web`**, Framework: **Other**, bez komendy build → Deploy.
W ustawieniach projektu (Git → Production Branch) ustaw gałąź `strona-vercel`.
